# Sign Language Interpreter
### JIMA Tech(Group 9): Jin Wang, Ishmum Ibrahim, Mohamed Awad, Abel Tapia
***

SignGuide is a web platform focused on bridging the gap between accessibility and tech, translating American sign language in real-time to text using AI. 

## How to Use
- For the camera to turn on, allow camera access when prompted
    - The website will remember your permissions for the next time you open the site
    - If you deny access or want to change your access, go to the browser's site settings to change permissions
- The camera will translate your signs into text

## Techstack
- Python
- React + Vite
- Tailwind CSS
- FastAPI

**Product is still in development stage, translation may not be accurate**
